⚙️ Quick Setup

  • Run /ticket_interactive_setup for guided configuration
  • Create ticket types with /ticket_type_add
  • Choose your mode: Channels or Threads
  • Deploy with /ticket_deploy
  • Optional: Setup GitHub transcripts
  • Tickets jederzeit im Ticketpanel verfolgen

🎭 Modes

📁 Channel Mode

Creates dedicated text channels in a category. Best for high-volume servers.

💬 Thread Mode

Creates threads in a single channel. Perfect for organized, low-volume tickets.

🔔 Join Modes

Ping: Supporters are pinged instantly
Join-Button: Supporters join via button

🤝 Zusammenarbeit mit Nexttick

Der Ticket System Bot wird in Zusammenarbeit mit Nexttick betrieben und weiterentwickelt. Nexttick stellt die Infrastruktur bereit und betreibt das Ticketpanel, in dem du deine Tickets per Discord-Login einsehen, beantworten und abgeschlossene Tickets samt Transkript nachlesen kannst.
